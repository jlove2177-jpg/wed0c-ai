## Product: Fable Meme Factory

An end-to-end automated pipeline: trend → curation → contract → render → compose → publish.

### Architecture

| Stage | Technology | What It Does |
|-------|-----------|--------------|
| Ingestion | Automated scraping | Scrapes trends every 4h with dedup |
| Curation | Multi-agent scoring | Scores content, picks the best angle |
| Contract | Structured output enforcement | Machine-readable spec for every asset |
| Render | Local + cloud rendering | Background + text compositing |
| QC | AI verification + retry | Pass/fail validation before publish |
| Publish | YouTube + X + Buffer | Multi-platform distribution |
